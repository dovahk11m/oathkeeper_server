# 관리자 패널 머지 후 서버 구동 오류 해결

**작성일**: 2025-12-01

## 문제 상황

관리자 패널 담당 팀원의 작업물을 머지한 후 서버 구동 실패

### 에러 메시지

```
org.springframework.util.PlaceholderResolutionException:
Could not resolve placeholder 'KAKAO_REST_API_KEY' in value "${KAKAO_REST_API_KEY}" <-- "${kakao.rest-api-key}"
```

## 원인 분석

### 에러 발생 경로

```
adminModelAdvice (빈 생성 실패)
  ↓ (의존성)
adminService (빈 생성 실패)
  ↓ (의존성)
@Value("${kakao.rest-api-key}") 주입 실패
  ↓ (원인)
환경 변수 KAKAO_REST_API_KEY 미설정
```

### 관련 파일

#### [AdminService.java](file:///c:/workspace/oath/src/main/java/com/oath/domain/members/service/AdminService.java#L61-L62)

```java
@Value("${kakao.rest-api-key}")
private String kakaoApiKey;
```

#### [application-local.yml](file:///c:/workspace/oath/src/main/resources/application-local.yml#L169-L171)

```yaml
kakao:
  rest-api-key: ${KAKAO_REST_API_KEY}
  js-key: ${KAKAO_JS_KEY}
```

### 문제 요약

- 관리자 패널에서 카카오 장소 검색 API 사용을 위해 카카오 REST API 키 필요
- `application-local.yml`에서 환경 변수 `KAKAO_REST_API_KEY` 참조
- 해당 환경 변수가 설정되지 않아 서버 구동 시 빈 생성 실패

## 해결 방안

### 방안 1: 기본값 설정 (권장 - 개발 환경) ✅

개발 환경에서는 기본값을 설정하여 환경 변수 없이도 서버가 구동되도록 함

**구현:**

```yaml
kakao:
  rest-api-key: ${KAKAO_REST_API_KEY:FAKE_KAKAO_KEY}
  js-key: ${KAKAO_JS_KEY:FAKE_KAKAO_JS_KEY}
```

**장점:**

- 팀원들이 별도 환경 변수 설정 없이 바로 개발 가능
- 로컬 개발 환경에서 즉시 서버 구동 가능

**단점:**

- 실제 카카오 API 기능은 유효한 키가 필요

### 방안 2: 환경 변수 설정

실제 카카오 API를 사용해야 하는 경우 환경 변수 설정

**Windows (PowerShell):**

```powershell
$env:KAKAO_REST_API_KEY="실제_카카오_REST_API_키"
$env:KAKAO_JS_KEY="실제_카카오_JS_키"
```

**영구 설정 (시스템 환경 변수):**

1. 시스템 속성 → 환경 변수
2. 사용자 변수 또는 시스템 변수에 추가
   - 변수 이름: `KAKAO_REST_API_KEY`
   - 변수 값: 실제 카카오 REST API 키

## 적용된 조치

### ✅ application-local.yml 수정

[application-local.yml](file:///c:/workspace/oath/src/main/resources/application-local.yml#L169-L171)에 기본값 추가:

