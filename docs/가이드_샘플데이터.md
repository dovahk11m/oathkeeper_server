# 샘플 데이터 생성 가이드

- **작성일:** 2025-11-20

이 문서는 `local` 프로파일에서 애플리케이션 시작 시, 테스트에 필요한 샘플 데이터를 생성하는 `DataInitializer`를 추가하는 방법을 설명합니다.

---

## 1. 핵심 아키텍처: 중앙 제어 방식

우리 프로젝트는 개별 `DataInitializer`의 실행 순서를 `@Order` 어노테이션에 의존하지 않습니다. 대신, **`MasterDataInitializer`가 모든 Initializer를 주입받아, 명시된 순서대로 직접 호출하여 실행 순서를 보장**합니다.

-   **장점:**
    -   데이터 간의 의존 관계(예: `Plan`은 `Member`가 먼저 생성되어야 함)를 코드 레벨에서 명확하게 제어할 수 있습니다.
    -   `@Order` 값의 충돌이나 불명확성으로 인한 실행 순서 오류를 원천적으로 방지합니다.

---

## 2. 새로운 샘플 데이터 추가 절차

새로운 엔티티(예: `Coupon`)에 대한 샘플 데이터를 추가하려면, 아래의 두 단계를 따릅니다.

### 2.1. [1단계] 개별 `DataInitializer` 클래스 생성

1.  **파일 생성:**
    -   **위치:** `src/main/java/com/oath/initializer/`
    -   **이름:** `DataInitializerXX_EntityName.java` 규칙을 따릅니다. (예: `DataInitializer15_Coupon.java`)
        -   `XX`는 다른 파일과 겹치지 않는 적절한 번호를 사용합니다.

2.  **클래스 구조:**
    -   아래 템플릿을 참고하여 클래스를 작성합니다. **`CommandLineRunner`를 구현하지 않는 것**이 중요합니다.

    ```java
    package com.oath.initializer;

    import lombok.RequiredArgsConstructor;
    import lombok.extern.slf4j.Slf4j;
    import org.springframework.context.annotation.Profile;
    import org.springframework.stereotype.Component;
    import org.springframework.transaction.annotation.Transactional;

    @Slf4j
    @Component
    @Profile("local") // local 환경에서만 실행되도록 설정
    @RequiredArgsConstructor
    public class DataInitializer15_Coupon {

        // 필요한 Repository 주입
        private final CouponRepository couponRepository;
        private final MemberRepository memberRepository;

        @Transactional("h2TransactionManager") // DB 작업을 위해 반드시 트랜잭션 지정
        public void initialize() {
            log.info("Initializing 15: Coupon sample data");

            try {
                // 데이터 생성 로직 구현
                Member targetMember = memberRepository.findById(1L).orElse(null);
                if (targetMember != null) {
                    Coupon coupon = Coupon.builder()
                                        .member(targetMember)
                                        .name("10% 할인 쿠폰")
                                        .build();
                    couponRepository.save(coupon);
                }
                log.info("Initialized coupon data.");

            } catch (Exception e) {
                log.error("Error initializing coupon data", e);
            }
        }
    }
    ```

3.  **핵심 규칙:**
    -   `@Component`와 `@Profile("local")`을 반드시 추가합니다.
    -   **`@Order` 어노테이션은 사용하지 않습니다.**
    -   **`CommandLineRunner`를 구현하지 않습니다.**
    -   데이터 생성 로직은 `public void initialize()` 메서드 안에 작성합니다.
    -   `initialize()` 메서드에는 **`@Transactional("h2TransactionManager")`**를 반드시 추가하여 트랜잭션 원자성을 보장하고 커넥션 문제를 방지합니다.

### 2.2. [2단계] `MasterDataInitializer`에 등록

1.  **파일 열기:** `src/main/java/com/oath/initializer/MasterDataInitializer.java`

2.  **의존성 주입:**
    -   생성자를 통해 새로 만든 `DataInitializer15_Coupon`을 주입받도록 필드를 추가합니다.

    ```java
    // ...
    @RequiredArgsConstructor
    public class MasterDataInitializer implements CommandLineRunner {

        // ... 기존 Initializer들
        private final DataInitializer12_Plan dataInitializer12_Plan;
        private final DataInitializer14_Review dataInitializer14_Review;
        private final DataInitializer15_Coupon dataInitializer15_Coupon; // <<< 새로 추가
        private final DataInitializer22_Visitor dataInitializer22_Visitor;
        // ...
    }
    ```

3.  **실행 순서 등록:**
    -   `run` 메서드 내부에서, 데이터 의존성을 고려하여 **정확한 순서에** 새로 만든 Initializer의 `initialize()` 메서드를 호출하는 코드를 추가합니다.

    ```java
    // ...
    @Override
    public void run(String... args) throws Exception {
        // ...
        dataInitializer12_Plan.initialize();
        dataInitializer14_Review.initialize();
        dataInitializer15_Coupon.initialize(); // <<< 새로 추가
        dataInitializer22_Visitor.initialize();
        // ...
    }
    ```

위 두 단계를 완료하면, 애플리케이션 재시작 시 새로운 샘플 데이터가 자동으로 생성됩니다.
