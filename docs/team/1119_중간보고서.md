# 1119: 중간 보고서

- **작성일:** 2025. 11. 19.
- **진행률:** 약 75%

---

## 1. 프로젝트 진행 현황 요약

-   2025년 11월 19일 기준 전체 공정률은 약 75%임.
-   기획했던 약속의 전 과정(생성-이동-도착-평가) 중 서비스의 뼈대가 되는 약속 관리, 중간 지점 추천, 위치 데이터 수집 및 저장 구조 구축을 완료함.
-   최근 팀원 변동으로 인해, 구현 난이도가 높은 일부 모듈의 통합 작업을 진행 중이며, 핵심 기능의 안정성 확보를 최우선 목표로 개발하고 있음.

---

## 2. 기획 대비 구현 현황

-   초기 기획의 방대함보다는 최소 기능 제품(MVP)의 완결성을 위해 구현 범위를 전략적으로 조정함.

| 카테고리 | 초기 기획 목표 | 실제 구현 현황 | 비고 |
| --- | --- | --- | --- |
| **약속관리** | 생성, 초대, 2차 제안, 자동 조율 | 생성, 초대, 시간 설정 완료 | 2차 제안 및 자동 조율은 추후 개발 예정 |
| **위치기능** | 실시간 이동 경로 시각화 | STOMP 기반 위치 전송 및 도착 판정 | 백엔드 소켓 통신 구현 완료, UI 부하 고려하여 갱신 주기 최적화 |
| **장소추천** | 중간지점 + 키워드 + 리뷰 | 중간지점 + 키워드 기반 추천 완료 | 핵심 추천 알고리즘 구현 성공 |
| **알림** | 미출발, GPS 미변화, 독촉 | 회원가입, 그룹/약속 생성 알림 | 시스템 알림 우선 적용, 독촉 로직은 백엔드 대기 |
| **통계/로그** | 시간 손해 시각화, 출발 로그 | 로그 DB 적재 및 합산 로직 완료 | 데이터는 정상 적재 중이나 시각화 모듈 미연결 |
| **수익/보상** | 광고, 결제, 포인트 | (보류) | 사용자 확보 후 도입 예정 |

## 3. 개발 상세 현황

-   **1) 사용자 및 그룹:**
    -   **로그인/프로필:** 이메일, 카카오, 페이스북 소셜 로그인 및 JWT 인증, 프로필 관리 구현함.
    -   **그룹 관리:** 그룹 생성, 멤버 초대 및 권한 관리 기능 안정화함.
-   **2) 약속 및 위치:**
    -   **약속 프로세스:** 플랜 생성 및 Google Matrix API 기반 경로 추천 로직 적용함 (90% - 확정 로직 UI 연결 단계).
    -   **위치 기술:** Flutter와 Spring Boot 간 STOMP/WebSocket 실시간 통신 채널 구축 완료함. 좌표 데이터 수신 및 DB 적재 정상 작동함.
    -   **지도 시각화:** 네이버 지도 SDK 연동 완료함. 실시간 마커 렌더링 부하를 줄이기 위해 입장 시 위치 전송 및 도착 판정 위주로 시나리오 최적화함.
-   **3) 데이터 및 관리:**
    -   **웹 관리자 패널:** 사용자/그룹 데이터 조회 및 관리 기능 구현함(70%). 통계 대시보드 UI 작업 중임.
    -   **로그 시스템:** 개인별 약속 이력 기록 및 그룹 전체 로그 합산 로직 구현 완료함 (Python 분석 서버 연동 대기).

## 4. 주요 이슈 및 해결 전략

-   **이슈:** 담당자 이탈로 인한 모듈 통합 지연
    -   **현상 (실시간 위치):** 백엔드 소켓 통신은 성공했으나, 프론트엔드 지도 상의 실시간 갱신 UI 연결이 매끄럽지 않음.
    -   **현상 (AI 로그 분석):** Python 분석 서버 구축은 완료되었으나 앱 API와의 통신 미연결됨.
-   **해결 전략:** 백엔드 중심의 데이터 정합성 확보
    -   **데이터 흐름 우선:** UI에서 화려하게 움직이지 않더라도, STOMP 프로토콜을 통해 서버에는 위치 로그가 실시간으로 적재되도록 조치하여 데이터 기반 앱의 정체성 유지함.
    -   **선택과 집중:** 불안정한 실시간 애니메이션 구현보다 정확한 현재 위치 표시와 도착 시간 타임스탬프 기록의 정확도를 높여 앱의 기본기 강화함.

## 5. 향후 계획

-   **단기 목표:** 금주 내 플랜 확정 기능 UI 연결 마무리 및 중간보고 피드백 반영 예정임.
-   **기술 목표:** 미연결된 Python 서버 코드를 분석하여, 현 인원으로 통합 가능한 범위 재산정함 (복잡한 분석 대신 단순 통계 우선 노출).
-   **최종 목표:** 약속이 잡히고 → 위치가 전송되고 → 도착이 기록되는 핵심 사이클의 완벽한 시연을 목표로 함.
