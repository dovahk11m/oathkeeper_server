# 1020: 초기 기획안

- **프로젝트명:** 약속 지킴이

# 🎯 한 줄 소개

**“신뢰 기반의 약속 문화”를 만들기 위한, 위치/시간 기반 약속 관리 및 추천 앱**

---

# 🧩 문제 인식

- 약속 시간에 늘 누군가는 지각한다.
- 항상 일찍 나오는 사람이 시간 손해를 본다.
- "출발했어"라고 말해도 믿기 어렵다.
- 약속 장소 정할 때 늘 애매하게 중간쯤에서 타협한다.
- 시간 손해, 거리 부담 등은 데이터 없이 감정적으로만 처리된다.
- 2차, 3차 약속 등 반복 약속에서 일정 조율이 어렵다.

---

## 💡 핵심 해결 아이디어

- 각자의 **출발 시간, 이동 거리, 도착 시간**을 실시간 추적
- **지각 벌금/출발 시간 통계**로 시간 손해 시각화
- 약속 목적에 따라 **맞춤형 장소 추천**
- **실시간 위치 공유**로 거짓말 방지
- **위치 기반 로그**로 공정하고 투명한 약속 기록
- **자동 일정 제안/조율** 기능 (2차 약속)
- **포인트/보상 시스템**으로 약속 참여 동기 부여
- **광고/제휴 기반 수익화** 가능성 보유

| 🚨 알림 시스템 | 미출발, GPS 미변화, 지각 등 상황별 알림 |

## 📍 장소 추천 고도화

### 키워드 기반 장소 선택

- 선택 키워드: **술 / 음식 / 대화 / 인스타 / 액티비티 등**
- 시간대/이동거리/분위기 고려
- 지역 예시 추천: 건대/홍대/성수/상봉/왕십리 등

### 기능 확장

- Kakao Maps API 또는 Naver Place API 기반
- 지역 내 **리뷰 많은 인기 장소** 카드형 UI로 노출
- **‘광고’ 뱃지 붙은 상점**은 광고 상품으로 처리

## 💸 수익화(비즈니스 모델) 방향

| 모델 | 설명 |
| --- | --- |
| 📌 **지각 벌금 정산** | 약속 후 지각자에게 송금 요청 (토스/카카오페이 연동) |
| 📌 **광고 상점 노출** | 장소 추천 결과에 광고 상점 우선 노출 |
| 📌 **제휴 예약 수수료** | 상점 상세 → 예약 연결 → 커미션 수익 |
| 📌 **프리미엄 기능** | 광고 제거, 정밀 추천, 통계 리포트 유료화 |

## 🧱 DB 설계 (핵심 테이블 요약)

| 테이블 | 주요 필드 |
| --- | --- |
| `members` | 사용자 정보 |
| `promises` | 약속 정보 (시간, 장소 등) |
| `promise_participants` | 약속 참가자 상태, 교통수단 |
| `location_snapshots` | 약속 전후 위치 데이터 (1h 전, 도착 시 등) |
| `departure_logs` | 출발 시각, GPS 변화 여부, 거짓말 여부 판단 |
| `departure_burden_stats` | 누적 손해 시간 통계 |
| `places` (선택) | 추천 장소 + 광고 여부 + 리뷰 등 정보 |
| `points_rewards` | 포인트, Oathkeeper 아이콘, 벌점/보상 기록 |
