# 1117 인수인계 작업 계획 (AI 연동 파트)

이 문서는 AI 연동 파트 인수인계 후, 기존 작업물을 기반으로 신규 기능을 구현하기 위한 단계별 작업 계획을 정의합니다.

---

### **오늘의 작업 계획 (Roadmap)**

#### **1단계: 기존 작업물 연결 테스트**

-   **주요 목표**: 떠난 팀원이 만든 AI 연동 파이프라인(`Rollup` → `Push` → `Fetch`)이 정상적으로 동작하는지 확인하여, 우리가 추가할 기능들이 올라갈 **기반이 튼튼한지 검증**합니다.
-   **핵심 작업**:
    1.  Python AI 서버를 로컬(`8001` 포트)에서 실행합니다.
    2.  Postman으로 `POST /api/plans/{planId}/metrics/refresh` API를 호출합니다.
    3.  Java 서버 로그를 보며 `MetricsRollupService`와 `MetricsPushService`가 에러 없이 순차적으로 실행되는지 확인합니다.
-   **의의**: 가장 중요한 첫 단계입니다. 만약 여기서 문제가 발생하면, 새로운 기능을 추가하기 전에 기존 로직을 먼저 수정해야 합니다.

#### **2단계: 플랜 기능 추가 (약속 완료 자동화)**

-   **주요 목표**: 1단계가 성공적으로 완료되어야만 진행할 수 있습니다. 수동으로 호출하던 통계 계산/전송 과정을 **"마지막 참가자가 도착했을 때" 자동으로 실행**되도록 자동화합니다.
-   **핵심 작업**:
    1.  `PlanService`의 `markArrival` 메서드를 수정하여, 모든 참가자가 도착했는지 확인하는 로직을 추가합니다.
    2.  모두 도착했다면 `PlanCompletedEvent`를 발행합니다.
    3.  이 이벤트를 수신하는 `PlanCompletionListener`를 생성하고, 이 리스너가 `MetricsRollupService`와 `MetricsPushService`를 호출하도록 구현합니다.
    4.  마지막으로 `Plan`의 상태를 `COMPLETED`로 변경합니다.

#### **3단계: 그룹 기능 추가 (그룹 스탯 누적)**

-   **주요 목표**: 2단계의 결과물에 의존합니다. 약속이 완료될 때마다, 그 약속의 통계 결과를 **소속된 그룹의 전체 '스탯'에 누적**시키는 기능을 구현합니다.
-   **핵심 작업**:
    1.  `Group` 엔티티에 누적 스탯을 저장할 필드(`totalLateMinutes` 등)를 추가합니다.
    2.  `Plan` 엔티티에 `Group` 정보를 연결할 필드를 추가합니다.
    3.  `PlanCompletionListener`의 로직을 확장하여, `Plan`의 통계 계산이 끝난 후, 해당 `Group`의 누적 스탯을 갱신하고 저장하도록 구현합니다.

---

이 순서는 **'기반 확인 → 개별 기능 구현 → 종합 기능 확장'**이라는 안정적인 흐름을 따르므로, 오늘 작업 계획으로 매우 적합합니다.
