# 1121d: 실시간 지도 기능 - 이동 상태(MovementStatus) 추가 작업 기록

## 1. 개요

실시간 지도 기능의 사용자 경험 향상 및 서버 로직 분기를 위해, 참가자의 이동 상태를 명확히 관리할 필요성이 제기됨. 기존 `ParticipantStatus`는 약속 참여 의사결정 상태만을 나타내므로, '이동 중', '정체 중', '도착 완료' 등 실시간 이동 상태를 표현하기 위해 `MovementStatus`를 도입하고 관련 로직을 구현함.

## 2. 구현 내용

### 2.1. `MovementStatus` Enum 정의

-   **목표:** 참가자의 실시간 이동 상태를 명확히 정의하고 관리.
-   **신규 파일:** `com.oath.domain.plan.MovementStatus.java`
-   **구현 내용:** 다음 상태들을 포함하는 Enum 정의.
    -   `HOME`: 약속 참여는 수락했지만, 아직 출발하지 않고 집에 있는 상태 (또는 출발 전 상태).
    -   `DEPARTED`: 출발 버튼을 눌렀거나, 위치 정보 전송이 시작된 상태.
    -   `MOVING`: 위치 변화가 감지되며 이동 중인 상태.
    -   `STATIONARY`: 위치 변화가 감지되지 않으며 정체 중인 상태 (아직 도착은 아님).
    -   `ARRIVED`: 약속 장소에 도착한 상태.

### 2.2. `Participant` 엔티티 수정

-   **목표:** `MovementStatus` 필드를 추가하고, 관련 상태 변경 로직 연동.
-   **수정 파일:** `com.oath.domain.plan.domain.Participant.java`
-   **구현 내용:**
    -   `movementStatus` 필드 추가 (`@Enumerated(EnumType.STRING)`, `@Column(nullable = false)`, `@Builder.Default(MovementStatus.HOME)`).
    -   `participantStatus` 필드에 `@Builder.Default(ParticipantStatus.PENDING)` 추가하여 견고성 강화.
    -   `markDeparted()`, `markArrived()`, `setParticipantStatus()` 메서드 내에서 `movementStatus`를 적절히 업데이트하도록 로직 추가.
    -   `setMovementStatus()` 메서드 추가.

### 2.3. `PlanService` 수정

-   **목표:** 참가자의 출발 및 도착 처리 시 `MovementStatus` 업데이트 연동.
-   **수정 파일:** `com.oath.domain.plan.service.PlanService.java`
-   **구현 내용:**
    -   `recordDeparture` 메서드에서 `participant.markDeparted()` 호출 시 `Participant` 엔티티 내부에서 `movementStatus`가 `DEPARTED`로 업데이트되므로 추가 수정 불필요.
    -   `updateParticipantArrivalStatus` 메서드에서 `participant.markArrived()` 호출 시 `Participant` 엔티티 내부에서 `movementStatus`가 `ARRIVED`로 업데이트되므로 추가 수정 불필요.

### 2.4. `TrackService` 수정

-   **목표:** 위치 정보 수신 및 감지 로직에 따라 `MovementStatus` 업데이트.
-   **수정 파일:** `com.oath.domain.locationevents.service.TrackService.java`
-   **구현 내용:**
    -   `storeTracks` 메서드 내에서 위치 수신 시 `movementStatus`를 `MOVING`으로 업데이트 (도착 상태가 아닌 경우).
    -   `detectGpsStationary` 메서드 내에서 정체 감지 시 `movementStatus`를 `STATIONARY`로, 움직임 감지 시 `MOVING`으로 업데이트.
    -   `detectArrival` 메서드 내에서 도착 감지 시 `movementStatus`를 `ARRIVED`로 업데이트.

## 3. 결과

`MovementStatus` Enum을 도입하고 `Participant` 엔티티 및 관련 서비스 로직에 연동함으로써, 참가자의 실시간 이동 상태를 명확하게 관리할 수 있게 됨. 이는 클라이언트의 UI 표시 및 서버의 고급 위치 추적 로직 분기에 활용될 예정임.
