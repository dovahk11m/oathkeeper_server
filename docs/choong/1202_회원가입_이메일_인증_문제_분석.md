   - 현재: 간단한 HTML 텍스트만 반환

#### AlarmEmail.java

```java
@Override
public void send(AlarmDTO request) {
    try {
        SimpleMailMessage simpleMailMessage = new SimpleMailMessage();
        simpleMailMessage.setFrom(fromEmail);
        simpleMailMessage.setTo(request.getTo());
        simpleMailMessage.setSubject(request.getSubject());
        simpleMailMessage.setText(request.getContent());
        javaMailSender.send(simpleMailMessage);
        log.info("[이메일 발송 성공 to: {}]", request.getTo());
    } catch (Exception e) {
        log.error("[이메일 발송 실패 to: {}, error: {}]", request.getTo(), e.getMessage());
        throw new RuntimeException("이메일 발송에 실패했습니다.", e);
    }
}
```

**확인 사항:**

- ✅ 로그 출력으로 발송 성공/실패 확인 가능
- ⚠️ 예외 발생 시 RuntimeException 던짐

### 2. 이메일 인증 처리 로직

#### MemberController.java

```java
@GetMapping("/verify")
public ResponseEntity<String> verifyEmail(@RequestParam("token") String token) {
    memberService.verifyEmail(token);
    String htmlResponse = "<html><body style='text-align:center; padding-top:50px; font-family:sans-serif;'>"
            + "<h1>인증 완료</h1>"
            + "<p>이메일 인증이 성공적으로 완료되었습니다.</p>"
            + "<p>이제 앱으로 돌아가 로그인을 진행해주세요.</p>"
            + "</body></html>";
    return ResponseEntity.ok().contentType(MediaType.TEXT_HTML).body(htmlResponse);
}
```

**문제점:**

- ❌ 간단한 HTML만 반환, 사용자 경험 부족
- ❌ 앱으로 돌아가는 명확한 방법 없음 (딥링크 미구현)

#### MemberService.java

```java
public void verifyEmail(String token) {
    Member member = memberRepository.findByEmailVerificationToken(token)
            .orElseThrow(() -> new Exception404("유효하지 않은 인증 토큰입니다."));

    if (member.getEmailVerificationTokenExpiry().isBefore(LocalDateTime.now())) {
        throw new Exception400("인증 토큰이 만료되었습니다. 다시 가입해주세요.");
    }

    member.activate();
}
```

**❗ 핵심 문제 발견:**

- ❌ **`member.activate()` 호출 후 `memberRepository.save(member)`를 하지 않음**
- ❌ **JPA 영속성 컨텍스트가 트랜잭션 종료 시 자동으로 flush되지만, `@Transactional` 어노테이션이 없을 수 있음**
- ❌ **변경 사항이 DB에 저장되지 않음**

## 🎯 해결 방안

### 문제 1: DB 저장 실패

**원인:**

- `MemberService.verifyEmail()` 메서드에서 `member.activate()` 호출 후 명시적으로 저장하지 않음
- `@Transactional` 어노테이션이 없거나 트랜잭션이 제대로 동작하지 않을 가능성

**해결책:**

```java
@Transactional
public void verifyEmail(String token) {
    Member member = memberRepository.findByEmailVerificationToken(token)
            .orElseThrow(() -> new Exception404("유효하지 않은 인증 토큰입니다."));

    if (member.getEmailVerificationTokenExpiry().isBefore(LocalDateTime.now())) {
        throw new Exception400("인증 토큰이 만료되었습니다. 다시 가입해주세요.");
    }

    member.activate();
    memberRepository.save(member); // 명시적 저장 추가
}
```

### 문제 2: 인증 완료 페이지 개선

**현재 문제:**

- 간단한 HTML만 반환
- 앱으로 돌아가는 명확한 방법 없음

**해결책:**

1. **전용 HTML 페이지 생성**

   - `src/main/resources/templates/email-verification-success.html` 생성
   - 디자인 개선 (CSS 스타일링)
   - 앱으로 돌아가기 버튼 추가

2. **딥링크 구현**

   - 앱 스킴 설정 (예: `oath://verification-success`)
   - 자동으로 앱 열기 시도
   - 앱이 설치되지 않은 경우 대체 안내

3. **에러 페이지 추가**
   - 인증 실패 시 별도 에러 페이지 표시
   - 재시도 방법 안내
