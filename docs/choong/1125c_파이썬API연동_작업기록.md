## 1. DTO 리팩토링 (완료)

- **작업 일시:** 2025-11-25
- **작업 내용:**
    - Python AI 서버의 v2 API 명세(`1125_API_v2_구현완료_회신.md`)에 따라, 그룹 요약 기능의 서버 통신에 필요한 DTO 클래스들을 재구성했습니다.
    - `com.oath.domain.metrics.dto` 패키지 내에 아래의 클래스들을 생성하여, AI 서버의 새로운 JSON 구조에 정확히 매핑되도록 준비했습니다.
- **산출물:**
    1.  `AiGroupSummaryStats.java`: AI가 계산한 통계 데이터의 상세 필드를 담는 DTO
    2.  `AiGroupSummaryResponse.java`: AI 서버의 전체 응답(`success`, `data`, `warnings`)을 파싱하기 위한 DTO
    3.  `AiGroupSummaryRequest.java`: AI 서버에 그룹 요약을 요청할 때 `planIds`, `style`, `notes`, `mode` 등의 파라미터를 담아 보낼 DTO

## 2. 서비스 로직 수정 (완료)

- **작업 일시:** 2025-11-25
- **작업 내용:**
    - `MetricsGroupService`의 비동기 메서드(`requestGroupSummaryAnalysis`)가 AI 서버 v2 스펙에 맞춰 통신하도록 수정했습니다.
    - 기존에 `Map`과 `String`으로 처리하던 요청/응답을, 새로 생성한 DTO(`AiGroupSummaryRequest`, `AiGroupSummaryResponse`)를 사용하도록 변경하여 타입 안정성을 확보했습니다.
    - AI 서버 응답에 `warnings`가 포함된 경우, 이를 로그에 기록하는 로직을 추가했습니다.
- **산출물:**
    - `MetricsGroupService.java` (수정)

---

## 3. 네트워크 설정 (완료)

- **작업 일시:** 2025-11-25
- **작업 내용:**
    - AI 서버의 `llm` 모드가 최대 30초 이상 소요될 수 있는 점을 고려하여, `java.net.http.HttpClient`를 사용하여 타임아웃 설정을 추가했습니다.
    - `HttpClient`의 연결 타임아웃(5초)과 요청 타임아웃(35초)을 명시적으로 설정하여, 긴 응답 시간 동안 커넥션이 끊어지는 문제를 방지했습니다.
    - `build.gradle`에서 `spring-boot-starter-webflux` 의존성을 제거하고, `spring-webflux` 의존성을 유지했습니다.
    - `application-local.yml`의 `spring.main.web-application-type: servlet` 설정은 제거했습니다.
- **산출물:**
    - `MetricsGroupService.java` (HttpClient 사용으로 변경)
    - `build.gradle` (수정)
    - `application-local.yml` (수정)

## 4. 문제 발생 시 복구 계획 (Rollback Plan)

> **참고:** 현재 구현은 `java.net.http.HttpClient`를 사용하며, 특별한 복구 계획은 필요하지 않습니다. 문제가 발생할 경우, 관련 코드 변경 사항을 직접 검토하여 원복해야 합니다.
