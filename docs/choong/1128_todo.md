## 5. 예상 이슈 및 대응 방안

### 5.1. AI 요약 폴링 관련

**예상 이슈:**

- PENDING 상태가 계속됨
- 타임아웃 처리 미흡

**대응 방안:**

- 서버 로그 확인 (`[plan-summary-fetch]`)
- AI 서버 상태 확인
- 최대 대기 시간 설정 권장 (30초)

### 5.2. WebSocket 연결 관련

**예상 이슈:**

- 연결 실패 (401 Unauthorized)
- 메시지 수신 안 됨

**대응 방안:**

- Authorization 헤더 확인
- 토픽 경로 확인 (`/topic/plans/{planId}/live`)
- 서버 로그 확인

### 5.3. 데이터 파싱 관련

**예상 이슈:**

- 필드명 불일치 (camelCase vs snake_case)
- null 값 처리

**대응 방안:**

- 실제 응답 예시 제공
- DTO 클래스 검증
